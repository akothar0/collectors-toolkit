── PRINCIPLES ──
· Reach for serif italic to add personality to the editorial moments — greetings, section heads, hero numbers.
· Geist Mono for anything where digits and identifiers earn their tabular character — money, percentages, cert numbers, timestamps, eyebrows.
· Geist sans is the workhorse for everything else.
· Never put serif italic in form fields, table headers, or eyebrows — it loses the contrast that makes it special.

Component

The slab.

CSS-only graded-slab placeholder. Renders as PSA / BGS / SGC / Raw at any size with one component.

Anatomy

1 · Plastic case
Linear gradient + inset highlight + soft shadow. Light flavor (paper) or dark flavor (graphite).
2 · Label band
Top 11% of slab. Grading-company red / navy / royal. Format: PSA 10 · GEM MT. Raw cards swap this for a mono "RAW · UNGRADED" line.
3 · Card window
Tinted gradient (team / parallel color) with refractor sheen, radial spotlight, and a stacked-ellipse silhouette to imply a player. Surname renders as serif italic in the accent color.
4 · Sport tag
Top-left, mono micro-text. NBA / NFL / MLB / WNBA.
5 · Card number watermark
Top-right, mono. #180.
6 · Bottom band
Set + year, mono, uppercase. Truncates with ellipsis when narrow.

Size matrix

The component is scale-invariant — every internal element is sized as a % of the slab width. Recommended sizes: 36 / 44 / 64 / 120 / 168 / 220.

Grading-company variants

Use the holding's grade string to select the label color. Pattern match: startsWith('PSA'), 'BGS', 'SGC', === 'Raw'.

── PRINCIPLES ──
· Whitespace is part of the design. Default page padding is 36px desktop, 20px mobile.
· A border-radius of 4px is the house standard. 6px for nav pills, 999px only for badges & circular avatars.
· Shadows are rare. The page reads from rules and whitespace, not floating cards.
· Numbers always tabular (use Geist Mono with font-feature-settings: 'tnum' on Geist sans where mixed).
